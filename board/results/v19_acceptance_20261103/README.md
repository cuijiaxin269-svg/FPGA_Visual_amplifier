## 实测覆盖及限制

| 项目 | 本次记录支持的结论 |
|---|---|
| 真实冷启动 | 3 次用户确认断电再上电，QSPI 状态和应用代码读回相符，均进入默认 STOPPED；不表示每次启动后全部外设业务均已验收 |
| 实体按键 | KEY0 按下、接受、完成各 2 次，并有用户确认 HDMI 切换效果 |
| 启停与触屏 | STOP 状态检查通过；触屏交互、HDMI 画面与频谱有用户现场确认及相应状态记录 |
| 采集与运行状态 | 最后一次只读核验仍运行，记录的采集、算法和频谱错误为 0；没有独立全时 HDMI 接收录像 |
| 稳定性 | 未完成连续 60 分钟固定参数验收。原段 2011.3 秒、重连检查 1 秒、续采 171.7 秒，累计有效观测 2184 秒（36 分 24 秒）；观测空档共 234.1 秒 |

人工操作和观察原话摘录见 [user_observations.json](user_observations.json)。其中包含触屏操作、实体按键、三次断电及 HDMI 观察的确认；此文件是观测摘录，并非完整 AI 对话导出。

稳定性测试中途调节增益后恢复为 12，频谱 epoch 从 3 变为 11。原采集段发生 `FT_Write failed`，续采发生 `Invalid context`，两次 JTAG 中断的根因未独立确定。结束时只读核验应用仍运行，不能据此补足采样空档或将本轮写为“长稳通过”。详见 [第一次中断](transport_interruption_01.json)、[第二次中断](transport_interruption_02.json) 和 [调参记录](spectrum_restart_01.json)。

首尾板内计数跨度为 2418.1 秒，含上述空档；处理计数增加 146004，平均约 **60.3796 FPS**，显示计数平均 **30.0 Hz**，频谱发布约 **4.9857 次/秒**。这些是对应 v19 版本的板内计数平均速率，不等于全时无间断像素采集、物理显示帧逐帧核验或端到端延迟。

- [小尺寸验证](golden_validation/)：64×64、128 帧，alpha 为 0/12/30/50。
- [全尺寸验证](golden_validation_full/)：1280×800、8 帧，alpha 为 0/12/30/50；最大绝对误差分别为 0/1/1/1 RAW10 码值。
