# 历史上板脚本

`original_v18/` 与 `original_v19/` 保存已有工程中的原始脚本，供追溯测试过程。它们包含旧路径、旧产物哈希、特定入口状态及版本条件；属于历史证据，不是本次 2025.2 构建的已验证下载入口。

作者已确认整套系统上板可正常使用；后续三次冷启动、交互与运行记录见 [v19 验收说明](../results/v19_acceptance_20261103/README.md)。原 v19 的 Flash 镜像保存在本地提交目录旁的 `release_assets/v19_2021_2/`，不能与 2025.2 构建程序混配。

`src/board_support/v19/` 的 QSPI 恢复代码绑定旧镜像的长度、哈希与执行条件。查阅这些脚本可追溯原过程；实际下载时应使用目标版本配套的镜像和初始化文件，不能直接沿用旧绝对路径。
