# 上板脚本状态

`original_v18/` 与 `original_v19/` 保存已有工程中的原始脚本，供追溯测试过程。它们包含旧路径、旧产物哈希、特定入口状态及版本条件；属于历史证据，不是本次 2025.2 构建的已验证下载入口。

本次整理和编译没有访问板卡。2025.2 新生成的 bit/XSA/初始化文件/ELF 尚需成套核对和上板验收。原 v19 的 Flash 镜像与一次冷启动结果位于提交目录旁的 `release_assets/v19_2021_2/`，不能与 2025.2 新构建的程序混配。

`src/board_support/v19/` 的 QSPI 恢复代码为既有特定镜像恢复过程的源码，其长度、哈希与执行条件绑定旧镜像。正式复现和演示前应形成针对最终版本的下载与恢复说明。
