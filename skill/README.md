# 可复用工程经验

本目录依据项目已有失败、修复和验证记录整理可复用经验，不依赖安装 Codex 全局技能。各指南供修改实现、排查故障或迁移硬件时按需使用，不是要求对当前可用整机重新执行的验收清单。项目当前待办见[收尾清单](../report/submission_gaps.md)。

| 指南 | 适用场景 | 使用方式 |
|---|---|---|
| [证据驱动的工程交接](evidence_handoff.md) | 多版本 FPGA 工程交接、确认一项测试属于哪个产物 | 先填写版本和证据表，再按验证层级形成结论 |
| [串口控制与设备状态验证](uart_state_validation.md) | 裸机 UART、人机界面、异步启停与参数提交 | 从字节接收到真实设备状态逐层验证，保留失败输入 |
| [启动镜像与冷启动验证](boot_image_verification.md) | Zynq 类系统启动包核对、区分烧录与自启动 | 绑定镜像组成，分别检查传输、存储读回、冷启动和业务功能 |

每篇均包含输入、流程、完成判据、失败来源及失效条件。原工程交接技能快照归档为 [original_handoff.txt](references/original_handoff.txt)，作为历史材料而非当前运行指令；其中旧路径和板上状态不应套用到当前环境。v18/v19 原始验收材料位于 `report/original_notes/`。

指南的案例来自本项目裸机软件和 RTL/HLS 实现，跨平台使用时按目标硬件调整条件。
