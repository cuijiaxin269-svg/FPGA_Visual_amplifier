# Zynq 7100 方框振动放大串口使用说明

适用于已固化到 QSPI Flash 的本地方框版。通过串口可以启动采集、开启方框、在运行中移动方框或改变边长，以及调节振动放大系数 α。启用方框后，框内显示振动放大结果，框外保留同一帧原画。方框大小决定处理结果的显示范围，物体的几何尺寸保持原样。

## 1. 接线和串口设置

使用接到板卡 **P4 的 HMI 控制串口（PS UART1）** 的 USB 转 TTL。上次实测该转接器在电脑上是 `COM8`。重新插拔后可在设备管理器的「端口（COM 和 LPT）」核对实际端口号。

| USB 转 TTL | Zynq 7100 板端 |
| --- | --- |
| TXD | P4.4，板端 RX |
| RXD | P4.3，板端 TX |
| GND | P4.1，GND |

使用 **3.3 V TTL 信号电平**。板卡由自己的电源供电，TTL 转接器只接上表三根线。板卡另有 UART0 调试口，方框指令 `MAGROI` 走 P4 的 HMI 控制口。接线细节见[板卡接线说明](../board/wiring/README.md)。

| 串口助手设置 | 值 |
| --- | --- |
| 端口 | `COM8`，以设备管理器为准 |
| 波特率 | 115200 |
| 数据位、校验、停止位 | 8 位、无校验、1 位（8N1） |
| 流控 | 无 |
| 发送模式 | 文本 / ASCII |
| 行结束 | **CRLF**，即实际发送字节 `0D 0A` |

命令使用大写，字段之间用一个英文空格，行尾直接跟 CRLF。若软件有「发送新行」选项，确认它添加的是 **CR+LF**。下面的命令均一行一发。

## 2. 从上电到显示方框

给板卡上电，摄像头接好，打开串口。刚上电时固件等待 `START`。下面用边长 256 像素的中央方框开始，发送 `START` 后等摄像头启动并出帧，再进行后续操作。

```text
VIEW 1
ALPHA 12
MAGROI 1 512 272 256 1
START
```

示例从序号 `1` 开始，适用于本次上电后还未发送过选区的板卡。若继续使用上次未断电的板卡，按最后一次成功序号加一。例如上次测试结束时成功序号为 `8`，中间无其他请求时，从 `9` 开始，把后续示例的序号也依次递增。

## 3. 移动、改大小和调 α

以下步骤延续第 2 节的序号。可以在采集运行中直接发送，每一步等输出显示更新后再进行下一步。

### 只移动方框

```text
MAGROI 2 832 160 256 1
```

左上角从 `(512, 272)` 移到 `(832, 160)`，边长仍为 256。坐标相对于 **1280×800 的摄像头原图**，原点在左上角，X 向右增加，Y 向下增加。HDMI 的 1920×1080 输出时序不参与选区坐标计算。

### 只改变方框大小

```text
MAGROI 3 832 160 384 1
```

左上角固定为 `(832, 160)`，边长从 256 改为 384。方框从这个左上角向右、向下扩展。

### 只调节振动放大系数

```text
ALPHA 24
```

方框位置和大小保持刚才的设置。固件会在处理帧之间应用新的系数。可在 `ALPHA 12` 和 `ALPHA 24` 之间切换观察同一个振动目标。α 的整数范围是 **0–50**，它是算法中的相位修正系数。需要用已知振幅的目标测量实际位移增益。

### 关闭方框或停止采集

关闭选区，保留当前视图的采集与输出。在 `VIEW 1` 下，画面恢复为整帧振动放大。

```text
MAGROI 4 832 160 384 0
```

想查看全画面原画时发送 `VIEW 0`。结束采集时发送 `STOP`。仅关闭电脑上的串口助手不会向 FPGA 发送 `STOP`。

## 4. 指令速查

| 指令 | 作用 |
| --- | --- |
| `START` | 启动连续采集，应用已设定的视图和参数 |
| `STOP` | 停止采集。再次 `START` 时沿用本次上电期间的设定 |
| `VIEW 0` | 全画面原画 |
| `VIEW 1` | 振动放大视图，适合单独看方框效果 |
| `VIEW 2` | 振动放大视图并显示频谱面板 |
| `MAGROI seq x y size enable` | 一次设置方框的坐标、边长和开关 |
| `ALPHA n` | 设置振动放大系数，`n` 为 0–50 的整数，可在运行中发送 |
| `EXPOSURE n` | 设置曝光行数，`n` 为 1–898 的整数，采集停止后发送，下次 `START` 生效 |

画面偏暗时，可先发 `STOP`，等采集停止后试发 `EXPOSURE 500`，再发 `START`。默认曝光为 320 行。曝光调节和 `ALPHA` 分别控制采集亮度和振动放大算法。

### MAGROI 参数规则

| 参数 | 填写方法 |
| --- | --- |
| `seq` | 0–65535。每次改变位置、边长或开关，使用上一个成功序号加 1。65535 后接 0 |
| `x`、`y` | 方框左上角坐标，均为非负整数 |
| `size` | 正方形边长，1–800 像素。实际观察建议从 256 开始 |
| `enable` | `1` 开启方框，`0` 关闭方框 |

- 必须满足 `x + size <= 1280`、`y + size <= 800`。关闭时也要填写有效坐标和边长。边框每侧占 2 像素，边长小于 5 时没有可见的内部区域。
- 相同序号可以重发同一组参数。若参数有变化，换新序号。仅重新打开串口或发送 `STOP` 不会清空序号。板卡重新上电后，方框默认关闭，α 恢复 12，可重新从序号 `1` 发送。
- 方框在 `VIEW 1` 或 `VIEW 2` 下显示。用 `VIEW 0` 看原画后，再切回放大视图即可使用此前设定的方框。

## 5. 用 Windows PowerShell 发送

可在 Windows PowerShell 粘贴运行下方脚本，再在 `FPGA>` 提示后逐条输入上面的命令。先关闭占用同一端口的串口助手。输入 `QUIT` 只退出电脑端脚本，结束采集应先输入 `STOP`。

```powershell
$portName = 'COM8'
$serial = [System.IO.Ports.SerialPort]::new(
    $portName, 115200, [System.IO.Ports.Parity]::None, 8,
    [System.IO.Ports.StopBits]::One
)
$serial.Handshake = [System.IO.Ports.Handshake]::None
$serial.DtrEnable = $false
$serial.RtsEnable = $false
$serial.Encoding = [System.Text.Encoding]::ASCII
$serial.NewLine = "`r`n"
$serial.WriteTimeout = 2000

try {
    $serial.Open()
    while ($true) {
        $command = Read-Host 'FPGA'
        if ($command -eq 'QUIT') { break }
        if ($command.Length -gt 0) { $serial.WriteLine($command) }
    }
} finally {
    $serial.Dispose()
}
```

## 6. 确认是否生效

- **看输出画面。** 在放大视图中，白色方框应出现在新位置，改变边长后应看到方框变大或变小。调 α 时可让摄像头对准一个有细微振动的目标。
- **使用 TTL 串口助手时。** 板端会发送 `sendme` 一类的串口屏查询字节。控制命令没有普通终端上的逐条文本 `OK` 回复。可用 HDMI 画面或 JTAG 读帧来确认，串口助手显示「已发送」只表明电脑发出了字节。
- **使用已接入协议的串口屏时。** 在主页面查看 `roi_status`、实际序号和位置。最新请求序号与 `roi_aseq` 一致、`roi_valid=1` 且状态为 `APPLIED` 时，代表该选区已进入输出。接入 TJC 屏的页面对象、回写格式和坐标映射见[屏端协议](roi_hmi_protocol.md)。
- **方框没变化。** 依次检查是否已发送 `START`、是否处于 `VIEW 1` 或 `VIEW 2`、串口行尾是否为 CRLF、选区是否越界、序号是否递增。若此前通过 UART0 调试口修改过处理频带，启用方框要求频带上限不超过 15 Hz，固件默认频带为 3–12 Hz。

本机已经用 COM8 和 JTAG 验证过中央方框 `(512, 272, 256)`、移动后的 `(832, 160, 256)`、同位置放大的 `(832, 160, 384)`，以及保持方框不变时 α 从 12 切到 24。
