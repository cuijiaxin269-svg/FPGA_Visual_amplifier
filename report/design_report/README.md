## 编译

使用XeLaTeX。当前环境为TeX Live 2026，字体为Windows宋体（SimSun）、黑体（SimHei）、Times New Roman和Consolas。

在此目录执行：

```powershell
./build.ps1
```

也可连续执行三遍：

```text
xelatex -interaction=nonstopmode -halt-on-error -file-line-error -jobname=report_competition_review main.tex
```

若迁移到其他系统，需要安装上述字体或在`main.tex`明确替换字体。首页按模板使用作品名称、摘要与关键字，不填写作者/学校信息；GitHub地址在首页和复现部分显著列出。章节与图表自动编号，公式编号连续；参考文献按GB/T 7714-2015顺序编码格式整理，无需BibTeX即可编译。
